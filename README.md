# MediLab — דף נחיתה

דף נחיתה של נתנאל יוחאי מדינה — שיעורים פרטיים לבגרות בביולוגיה (5 יח״ל) ובביוטכנולוגיה (10 יח״ל), וספרי עזר לבגרות.

## מבנה הפרויקט

```
.
├── index.html       # הקובץ הראשי
├── assets/          # תמונות (לוגו, פורטרט, ממליצים, כריכות ספרים)
└── README.md
```

## העלאה ל-GitHub Pages

1. צרו ריפו חדש ב-GitHub (לדוגמה: `medilab-landing`)
2. העלו את כל הקבצים בתיקייה זו לריפו (גרירה למסך ה-Upload)
3. הגדרות → Pages → Source: `Deploy from a branch` → Branch: `main` / root
4. תוך כמה דקות הדף יהיה זמין בכתובת: `https://USERNAME.github.io/medilab-landing/`

## דומיין משלך

אחרי שהדף עולה, אפשר לחבר דומיין דרך:  
Settings → Pages → Custom domain → הוספת הדומיין שלכם.
